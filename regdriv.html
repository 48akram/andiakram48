Syarat & Ketentuan
Pasal 1 — Kejujuran 1. Driver wajib jujur dalam menjalankan tugas pengantaran.
2. Dilarang memanipulasi harga ongkir kepada pelanggan.
Pasal 2 — Ketentuan Driver 1. Driver tidak sedang terikat secara eksklusif dengan komunitas/kelompok kurir tertentu. Pengecualian diperbolehkan untuk platform seperti Grab/Gojek selama bersifat fleksibel (on-bid/non-eksklusif).
2. Driver tidak diperkenankan menjalankan atau menerima order lain (termasuk Grab/Gojek atau japri) selama sedang memproses order dari sistem.
3. Driver dilarang menerima order japri dari pelanggan yang terdaftar dalam sistem/database.
4. Order dari pelanggan pribadi di luar database diperbolehkan, selama tidak mengganggu order dari sistem.
5. Driver wajib memprioritaskan order dari sistem. Dilarang mendahulukan atau mengalihkan prioritas ke order lain yang masuk setelah order sistem diterima.
Pasal 3 — Sistem Order 1. Seluruh order WAJIB melalui sistem resmi.
2. Driver dilarang menerima order langsung (jalur pribadi/japri) dari pelanggan.
3. Jika pelanggan menghubungi langsung, Driver wajib mengarahkan pelanggan untuk melakukan pemesanan melalui sistem atau melalui Admin.
4. Pengecualian hanya berlaku jika Admin tidak memberikan respon dalam waktu ±3 menit, maka Driver diperbolehkan mengambil order tersebut dengan tetap melaporkan ke Admin.
Pasal 4 — Sanksi & Denda 1. Jika terbukti mencuri barang/uang, Driver bersedia dilaporkan ke pihak berwajib dan didenda 10x lipat nilai barang.
2. Membatalkan order sepihak >3x tanpa alasan jelas = Akun dibatasi.
3. Menerima order di luar sistem tanpa izin akan dikenakan sanksi sesuai kebijakan Admin.
4. Pelanggaran kode etik berat akan dikenakan sanksi pemberhentian sebagai Driver tanpa kompensasi.
Pasal 5 — Persetujuan Dengan mencentang kotak di bawah, saya menyatakan data yang saya isi adalah BENAR dan saya siap menerima konsekuensi hukum apabila melanggar perjanjian ini.
